# Настройка SMTP для отправки заказов на email

## Настройка Gmail SMTP

1. **Создайте пароль приложения Gmail:**
   - Перейдите на https://myaccount.google.com/
   - Включите двухфакторную аутентификацию (если не включена)
   - Перейдите в раздел "Безопасность" → "Пароли приложений"
   - Создайте новый пароль приложения для "Почта" и "Другое устройство"
   - Скопируйте сгенерированный пароль (16 символов)

2. **Добавьте переменные окружения в `.env` файл сервера:**
   ```env
   SMTP_USER=ваша_почта_для_отправки@gmail.com
   SMTP_PASSWORD=ваш_пароль_приложения_16_символов
   ORDER_EMAIL=artem.ger134@gmail.com
   ```

   Где:
   - `SMTP_USER` - почта, с которой будут отправляться письма (нужен пароль приложения для этой почты)
   - `SMTP_PASSWORD` - пароль приложения Gmail для почты из `SMTP_USER`
   - `ORDER_EMAIL` - почта, на которую будут приходить заказы (может отличаться от `SMTP_USER`)

3. **Важно:**
   - Используйте именно пароль приложения, а не обычный пароль от Gmail
   - Пароль приложения выглядит как строка из 16 символов без пробелов
   - Храните пароль приложения в безопасности

## Тестирование

После настройки SMTP, при оформлении заказа на сайте, письмо будет отправлено на `artem.ger134@gmail.com` с деталями заказа в HTML формате.
